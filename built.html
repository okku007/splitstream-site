How it's built

one core, quietly doing the work

SplitStream is a Kotlin Multiplatform app. One shared core owns sync, the cache and every number a widget shows. Each platform draws it in its own native UI.

widgets never wait for the network

The app syncs and publishes snapshots. Widgets only read them, so they draw instantly and stay filled offline.

SourcesJolpica and Formula1.comSchedule, standings and results. Official session times override when they shift.
Shared coreOne repositoryHashes each payload and only rewrites the SQLDelight cache when something changed.
SnapshotsReady to drawSmall serialized models, one per widget, written after every sync.
SurfacesApp and widgetsCompose and RemoteViews on Android. SwiftUI and WidgetKit on iOS.

refresh when it matters

Every 30 seconds while a session is live, every 15 minutes near a race weekend, every six hours otherwise. Manual refresh waits a minute between pulls, app-wide.

built for every size

Each widget has its own layout for small, medium, large and extra large, matched to your home screen grid. Drag to resize and it switches to the layout that fits, with nothing cut off or stretched.
